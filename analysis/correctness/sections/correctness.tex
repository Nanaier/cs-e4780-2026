\subsection{Correctness}
\label{sec:correctness}

We do not judge correctness by inspection. \texttt{reference.py} computes both queries as a batch job in DuckDB:
window assignment and close price with SQL window functions, then the EMA recurrence and crossovers per symbol.
With \texttt{--late-bound-ms} it drops exactly the ticks that a stream with that out-of-orderness bound drops,
by comparing each tick with the running maximum event time of the ticks before it in feed order.
\texttt{diff.py} joins an engine's output with the reference on (symbol, window end) and counts EMA rows and
advisories that are missing, extra or different (prices and EMAs to a relative $10^{-9}$, advisory kinds,
and ISIN and currency when present).

Table~\ref{tab:correctness} lists every run we verified this way on real data. All 23 are identical to the
reference: Flink reading the files and reading Kafka at $p=1,2,4$, with Kafka's default partitioner and with a
balanced partition map, with 10\,s checkpoints and exactly-once or at-least-once sinks, after a TaskManager was
killed mid-run, on single exchanges, and with 1 to 10{,}000 subscribers. In total 32.7\,M result rows were
compared without a single difference. After the TaskManager kill with at-least-once sinks, the collector
received 74{,}308 replayed rows twice; every duplicate was equal to the row it duplicated, so dropping them
restores the reference. The 28 unit tests of the window, EMA, subscription, heartbeat, metadata and dashboard logic pass.

Agreement on the week does not prove agreement in general, because the week has almost no ticks close to the
300\,ms bound. We therefore also ran every engine on three synthetic days that contain ticks arriving a few
seconds late, with a 2\,s bound. The reference and the Python engine drop the same 10 ticks. Flink in file mode
kept all 10 at $p=1,2,4$ in the logged run (9 at $p=2$ in an earlier one), so 1{,}626 EMA rows and 8
advisories differed: its watermark is
emitted every 200\,ms of processing time and trails the data when files are read at full speed. With
\texttt{--watermark-every-event} (Section~\ref{sec:implementation}) Flink equals the reference at $p=1,2,4$.
