\subsection{Dashboard}
\label{sec:dashboard}

The results are meant for traders, so we built a dashboard that answers ``which of my symbols is trending, and since when?'' at a glance (Figure~\ref{fig:dashboard}).
\texttt{trading/viz.py} turns the \texttt{ema.csv} and \texttt{advisories.csv} of any engine into one self-contained HTML page.
A watchlist on the left shows, for each symbol, its current trend (EMA38 above or below EMA100), its exchange and security type, and its latest advisory; it can be filtered by exchange, security type and trend, searched by symbol or ISIN, and sorted by latest signal or number of crossovers.
The main panel plots the closing price per window with both EMAs and the advisories as markers.
Below it, a trend panel shows the gap $\mathrm{EMA}_{38}-\mathrm{EMA}_{100}$ in percent of $\mathrm{EMA}_{100}$, shaded green above zero and red below, so that every advisory is visible as a zero crossing.
A market-breadth histogram counts buy minus sell advisories per hour over the symbols that match the filters.
First-window advisories (Section~\ref{sec:design-space}) are hidden by default and shown as grey warm-up markers on request, and the price axis follows the closing prices so that the EMA warm-up from zero does not flatten the chart.
